# GD Expense Tracker — by GD Tech Academy

Mobile-first income & expense PWA. Personal Mode (device only) + Shared Mode (Secret Keys, Google Sheets sync).
Stack: HTML/CSS/vanilla JS · Google Apps Script · Google Sheets · Google Drive · IndexedDB.

- **Guide (Hinglish):** `docs/DEPLOY.md`
- **Backend:** `backend/Code.gs`
- **Blogger single-file build:** `node tools/build-blogger.js` → `dist/`
- **Sample data:** `docs/sample-backup.json` (Settings → Backup → Import)
- **Tests:** `tests/backend.test.js`, `tests/e2e.js`
